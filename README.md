# 分切单、取样目录和裁床凭据

本地演练资料使用虚构的实物、机构和记录编号。经营单据存放于 `data/`，包括 `orders.json`、`cuts.json`、`warehouse.json`。来源原件在提供时由资料端送出。

## 资料约定

布面按毫米表示，区间左闭右开。操作单的有向端点指定子卷与母卷之间等长映射，倒卷时方向依据端点分别应用，横向先按修边留幅然后按 flip_width 判断左右。条带最小采样密度是每个指定网格每项目至少一份有效观察，不由单个整卷合格证替代。suspect 切点的两个候选区间都要保留，复尺引用操作号并给出确认值。成套段以发货清单划定。补领额度按轮、母卷分别计数。

根路径列出资料入口。各路径每次请求依次返回该路径的演练响应，最后一条响应保持不变。不同路径有各自的请求计数。重启资料端从首条响应开始。路径清单中的链接相对同一服务。非演练路由的原件对应 `originals/` 下同名路径，经营单据也可以从 `/data/文件名.json` 直接领取。

## 运行资料端

运行依赖为 Python 3.11 标准库。

```sh
python3 source_service.py --port 8040
```

以下命令核对本地资料服务和交互。

```sh
python3 -m unittest discover -s tests -v
```
